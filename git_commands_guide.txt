====================================================================
               دليل أوامر Git والعمليات المنفذة في المشروع
====================================================================

1️⃣ التحقق من حالة الفروع والتغييرات الحالية:
--------------------------------------------------
- فحص حالة التغييرات المفتوحة وغير المحفوظة:
  git status

- عرض كافة الفروع المحلية والبعيدة (Remote):
  git branch -a

- عرض تفاصيل الفروع والكوميت المرتبطة بالـ Remote:
  git branch -vv


2️⃣ حفظ التغييرات وتأمينها (Commit / Stash):
--------------------------------------------------
- إعداد وحفظ جميع الملفات والتعديلات:
  git add .

- تسجيل التعديلات بكوميت رسمي:
  git commit -m "عنوان التعديل"

- حفظ التعديلات المؤقتة جانباً بدون كوميت (عند الحاجة للتنقل السريع):
  git stash

- استرجاع التعديلات المخبأة:
  git stash pop


3️⃣ التبديل بين الفروع ودمج التغييرات (Merge Flow):
--------------------------------------------------
- الانتقال إلى فرع التطوير (devlopment):
  git checkout devlopment

- سحب أحدث الكود من السيرفر:
  git pull origin devlopment

- دمج الفرع الفرعي داخل الفرع الحالي:
  git merge اسم_الفرع_المراد_دمجه

- رفع نتائج الدمج لفرع التطوير في GitHub:
  git push origin devlopment


4️⃣ إنشاء فرع جديد وإعداده على الـ Remote:
--------------------------------------------------
- إنشاء واختيار فرع جديد (مثال: adding-map):
  git checkout -b adding-map

- رفع الفرع الجديد لأول مرة للـ Remote وتتبعه:
  git push -u origin adding-map


5️⃣ دمج وتحديث فرع Production الرئيسي (Master):
--------------------------------------------------
- الانتقال للفرع الرئيسي:
  git checkout master

- دمج التحديثات المكتملة من devlopment إلى master:
  git merge devlopment

- رفع التحديثات إلى سيرفر GitHub:
  git push origin master


6️⃣ حذف الفروع القديمة (Local & Remote):
--------------------------------------------------
- حذف فرع محلي بعد دمج كوده:
  git branch -d اسم_الفرع

- حذف فرع محلي بالقوة (إذا لم يكتمل الدمج):
  git branch -D اسم_الفرع

- حذف الفرع البعيد من سيرفر GitHub:
  git push origin --delete اسم_الفرع


7️⃣ حل مشكلة البورت المعلق في Flutter Web (SocketException 10048):
------------------------------------------------------------------
- إغلاق العملية المعلقة التي تحجز البورت 50253 في PowerShell:
  Get-NetTCPConnection -LocalPort 50253 -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
